# Password Manager

A command-line Password Manager built with Python.

## Features

- User registration and login
- Secure master password hashing using bcrypt
- Password encryption using Fernet
- SQLite database
- Generate strong random passwords
- Add, view, update and delete passwords
- Search passwords by website
- Search passwords by category

## Technologies

- Python 3
- SQLite3
- bcrypt
- cryptography (Fernet)

## Installation

Clone the repository:

```bash
git clone https://github.com/quirkyboi/Password-Manager.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```
